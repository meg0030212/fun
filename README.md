# Lumen 筆記

一個以 Notion 為靈感的全功能筆記與知識管理工作區，採用相同的版面配置（左側頁面樹側邊欄、上方麵包屑工具列、置中的區塊編輯器）。
以 React + TypeScript + Vite 打造，所有資料儲存在瀏覽器的 localStorage 中，不需要伺服器或帳號。

## 快速開始

```bash
npm install
npm run dev        # 開發模式 http://localhost:5173
npm run build      # 產生 dist/ 靜態網站
npm run build:single  # 產生單一 HTML 檔 dist-single/index.html
```

## 功能

### 區塊編輯器
- 頁面中的簡單表格：「新增列」「新增欄」可按住往下／往右拖，一次新增多列或多欄
- 區塊類型：文字、標題 1/2/3、項目符號清單、編號清單（多層 1. / a. / i.）、待辦清單、切換清單、引言、標註（可換圖示與底色）、分隔線、程式碼（可選語言、複製）、圖片（上傳／連結、可調整寬度、說明文字）、網頁書籤、嵌入（iframe）、影片（YouTube／Vimeo）、方程式（KaTeX）、目錄、簡單表格、子頁面、內嵌資料庫
- `/` 指令選單（中英文關鍵字搜尋）、`@` 提及頁面與日期、反向連結
- Markdown 快捷鍵：`#` `##` `###` `-` `*` `1.` `[]` `>` `"` ```` ``` ```` `---`，行內 `**粗體**` `*斜體*` `` `程式碼` `` `~~刪除線~~`
- 選取文字顯示格式工具列：轉換成、連結、粗體、斜體、底線、刪除線、行內程式碼、文字顏色／背景色、清除格式
- 區塊左側 `+` 與 `⋮⋮` 拖曳把手：拖曳排序、刪除、複製、轉換成、顏色、複製區塊連結
- Tab／Shift+Tab 縮排、Enter 分割、Backspace 合併、方向鍵跨區塊移動
- Esc 或滑鼠框選以選取多個區塊，可刪除、複製（Ctrl+D）、剪下／複製為 Markdown
- 貼上多行文字自動轉為區塊、貼上圖片自動建立圖片區塊、拖放圖片檔案
- 全域復原／重做（Ctrl+Z／Ctrl+Shift+Z）

### 頁面
- 無限層級巢狀頁面、圖示（表情符號或圖片連結）、封面（漸層、顏色、上傳、連結）
- 字型樣式（預設／襯線／等寬）、小字體、全寬、鎖定頁面
- 我的最愛、建立副本（含子頁面與資料庫）、移至、垃圾桶（還原／永久刪除／清空）
- 頁面留言面板、字數統計、建立與編輯時間
- 匯出 Markdown／HTML、列印為 PDF、匯入 Markdown

### 資料庫
- 整頁資料庫與內嵌資料庫，每一列都是可編輯的完整頁面（側邊預覽視窗開啟）
- 屬性類型：標題、文字、數字（多種格式）、選取、多選、狀態、日期、核取方塊、網址、電子郵件、電話、建立時間、上次編輯時間
- 檢視：表格、看板、清單、畫廊、行事曆，可新增多個檢視、重新命名、複製、刪除
- 篩選（多條件）、排序（多層）、搜尋、隱藏屬性、欄寬調整、拖曳欄位與列排序
- 公式屬性：與 Notion 相同的寫法（`prop("價格") * prop("數量")`、`if()`、`dateBetween()`、`map()`… 約 70 個函式），編輯視窗有即時預覽、錯誤提示與函式說明
- 填滿控點：選取表格中的一格後拖曳右下角小方塊，往上或往下填入內容；拖過最後一列會自動新增列。日期每格加一天、結尾有數字的文字會遞增（第1週 → 第2週），按住 Ctrl 只複製；Ctrl+Z 一次復原
- 方向鍵在格子間移動（類似試算表）
- 表格底部計算列（計數、總和、平均、最小／最大、勾選百分比…）
- 看板拖曳卡片換群組、新增群組；行事曆拖曳變更日期、點擊日期新增

### 電子手帳
- 像紙本手帳的計畫頁：每一頁代表一個月、一週或一天，可往前後翻頁，每頁內容分開保存
- 區塊自由組合：月曆、時段表（上午／下午／晚上、自訂時段或每小時）、清單（待辦／目標）、行程（連結資料庫）、習慣追蹤、筆記；可調整寬度、高度、顏色與順序
- 紙張樣式（空白、方格、點點、橫線）與主題色；待辦可帶入上一期未完成的項目
- 資料來源：手帳可連結多個資料庫（例如工作排程、私人行程），各自設定篩選（例如「類別 是 工作」）、顏色，並可在手帳上方一鍵顯示／隱藏；從手帳新增的行程會自動填入篩選的值；每個區塊也能選擇要顯示哪些來源
- 5 個內建模板，也能把自己的版面（含連結的資料來源與篩選）存成模板重複使用（會隨同步到其他裝置）
- 從側邊欄「新增電子手帳」或在頁面輸入 `/手帳` 建立

### 工作區
- 側邊欄：工作區切換、搜尋、首頁、設定、我的最愛、私人頁面樹（拖曳排序與巢狀）、範本、匯入、垃圾桶；可調整寬度與收合
- 快速搜尋（Ctrl+K，搜尋標題與內文）、首頁（最近造訪、即將到來、最近編輯）
- 範本：待辦清單、會議記錄、日記、週計畫、專案看板、閱讀清單、習慣追蹤、團隊知識庫
- 年份可顯示為西元或民國（設定 → 外觀），日期欄位也可單獨選「民國115年11月23日」或「115/11/23」格式；匯入時可辨識民國日期，公式有 `rocYear()` 與 `formatDate` 的 `R`（民國年）
- 淺色／深色／跟隨系統主題、繁體中文介面、手機版自適應
- 設定：個人名稱、工作區名稱、主題、匯出／匯入整個工作區 JSON 備份、重設

## 從 Notion 匯入

側邊欄「匯入 → 從 Notion 匯入」：在 Notion 匯出時選 **Markdown & CSV**（包含子頁面、為子頁面建立資料夾），直接選擇下載的 .zip 檔，不需解壓縮。會保留頁面層級、子頁面、資料庫（自動辨識文字、數字、選取、多選、狀態、日期、核取方塊、網址、電子郵件欄位，並建立表格／看板／行事曆檢視）、資料列頁面內容、待辦、標註、表格、程式碼、圖片（單張 400 KB 以內，總計約 2.5 MB）與頁面間的連結。公式、關聯、彙總欄位以文字匯入；留言、頁面歷史與權限不會匯入。

## 同步到 Google 雲端硬碟

在「設定 → 同步」（或側邊欄底部的雲朵圖示）開啟。有兩種方式：

1. **Google 雲端硬碟（網頁連線，建議）**：電腦、手機、平板都能用。工作區存成雲端硬碟中的「Lumen 筆記工作區.json」。需要先在 Google Cloud Console 建立一次 OAuth 用戶端 ID（設定頁面內有逐步說明），並把 Lumen 的網址加入「已授權的 JavaScript 來源」。
2. **電腦上的 Google 雲端硬碟資料夾（免設定）**：安裝「Google 雲端硬碟電腦版」後，把同步檔案建立在「Google 雲端硬碟」資料夾中即可。僅支援電腦版 Chrome／Edge。

合併規則：每個頁面與資料庫各自保留最後修改的版本；永久刪除會同步到其他裝置；新裝置若只有範例內容，會直接採用雲端資料。

### 端對端加密

在「設定 → 同步 → 端對端加密」設定密碼後，上傳的檔案會先在瀏覽器中加密（PBKDF2-SHA256 60 萬次迭代衍生金鑰 + AES-256-GCM），Google 或任何取得檔案的人都無法讀取內容。密碼不會上傳；每台裝置第一次同步時輸入一次，之後以不可匯出的金鑰記在該裝置上。變更密碼後，其他裝置會要求輸入新密碼。「資料與備份」也可匯出加密備份檔。

忘記密碼就無法讀取雲端與加密備份中的資料（各裝置本機的資料不受影響）。加密只保護雲端檔案與備份檔，瀏覽器中的本機資料仍為未加密。

## 部署（GitHub Pages）

推送到 `main` 時，`.github/workflows/deploy.yml` 會自動建置並發佈到 GitHub Pages。第一次使用前，請到倉庫的 **Settings → Pages**，把 **Source** 設為 **GitHub Actions**。發佈網址為 `https://<帳號>.github.io/<倉庫名稱>/`。

## 與 Notion 的差異

資料存在瀏覽器中，可透過 Google 雲端硬碟在多個裝置間同步。以下功能未包含：多人即時協作（同時編輯同一頁面時以較晚儲存者為準）、帳號與權限、發佈到網路、AI、資料庫的關聯／彙總屬性、時間軸檢視。

## 專案結構

```
src/
  store.ts          資料狀態、持久化、復原／重做、頁面與資料庫操作
  seed.ts           首次開啟的範例內容
  templates.ts      範本
  markdown.ts       Markdown 匯入／匯出
  sync/             Google 雲端硬碟與本機檔案同步、合併邏輯
  components/
    Editor.tsx      區塊編輯器（鍵盤、拖放、選取、指令選單）
    Blocks.tsx      圖片、嵌入、方程式、表格等區塊
    PageView.tsx    頁面（封面、圖示、標題、屬性）
    Sidebar.tsx     側邊欄與頁面樹
    Topbar.tsx      麵包屑與頁面選單
    FormatToolbar.tsx 文字格式工具列
    Panels.tsx      搜尋、設定、範本、留言、首頁、預覽視窗
    db/             資料庫檢視、屬性、篩選排序
```
